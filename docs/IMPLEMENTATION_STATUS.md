# Статусы модулей

Живой пульс Apple Watch / SE 1 (2026-11-11) — **Implemented, Linux-tested; physical validation pending**. Общий HealthKitLiveHeartRateService собирает пульс на Watch в явной HKWorkoutSession; WatchConnectivity передаёт свежие события непосредственно на iPhone. Выбор Apple Watch в «Трекере» включает собственный источник, не запускает AirPods и не запрашивает историю HealthKit. UUID/sequence/time guards защищают от старых событий; пауза/смена источника/завершение останавливают сбор. Пульс хранится отдельно от Workout/CloudKit, старые записи совместимы; HKWorkout builder отбрасывается, экспорт отдельный. Полный Linux-прогон: 293 Core tests, portable Watch delivery/state/persistence и все прежние проверки. Watch SDK build под watchOS 10 и iOS SDK build прошли. 101 Apple unit tests и UI-настройка Watch прошли в `WatchLive-20261111.xcresult`; AirPods UI в первом прогоне превысил лимит на фоне высокой нагрузки Mac, отдельный повтор `WatchLiveAirPodsRetry-20261111.xcresult` прошёл. Снимок настройки Watch просмотрен. Первичная подпись по SSH остановилась на `errSecInternalComponent`; сборка из интерактивного Terminal на Mac прошла, `codesign --verify --deep --strict` успешен. Сертификат/ключ не экспортировались. Установка и живой датчик на физических SE пока не подтверждены: developer-связь с Mac отсутствует; перенос Personal Team через приложение Watch отклоняется Code=111. [Инструкция](WATCH_HEART_RATE.md).

watchOS 10+ и три режима будильника (2026-11-10) — **Implemented, Linux-tested**. По запросу пользователя Watch target и Core допускают watchOS 10+, включая SE 1; iPhone остаётся iOS 26+. На Watch 10–11 нативные bordered-кнопки, на 26+ сохранён Glass через availability. Режимы: «На iPhone» (фиксированный AlarmKit без нашей Watch session), «На Apple Watch» (передача после свежего подтверждения) и «На всех устройствах» (прежний `phoneAndWatch`, телефонный резерв сохраняется). Автоматическое зеркалирование AlarmKit на часы контролируется iOS и объяснено в форме. Подсказки различают отсутствие пары/установки и недоступность установленного приложения. Полный Linux-прогон: 292 Core tests и portable/static/resource checks. Xcode 27.2: device-сборка Watch для `arm64_32-apple-watchos10.0` и `arm64-apple-watchos10.0` прошла; физические SE появились в доступных destinations схемы. 101 Apple unit tests и три UI-сценария выбора/сохранения направлений прошли (`Watch10DeliveryUI-20261111`, `Watch10DeliveryUIComplete-20261111`). Каталог локализации компилируется. Подписанная установка, UI и ночной сценарий на физических SE 1 остаются непроверенными.

Интерактивный дневник сна (2026-11-10) — **Implemented, Linux-tested**. Компактная раскрывающаяся плашка будильников перенесена наверх, добавлены миниатюры, изменение времени/окна/доставки, выключение сохранённого плана. Круговая диаграмма и шкала фаз поддерживают выбор; график 7/30 ночей переключает выбранную ночь и показывает среднее/минимум/максимум без подстановки нулей. Дополнительно: доли фаз, зарегистрированное бодрствование, непрерывный сон и, при достаточном покрытии, засыпание/доля сна в постели. «Только Apple Watch» доступен при подтверждённой связи; резерв iPhone выключается лишь после свежего подтверждения запланированного Watch-сигнала. Подтверждённая передача и очистка незавершённого системного сигнала переживают перезапуск; старые настройки сохраняют резерв. Полный Linux-прогон: 291 Core tests, portable/static/resource/localization checks. Xcode 27.2: SDK-сборка, 101 Apple unit tests и три UI-сценария прошли в `SleepInteractiveFinal-20261110.xcresult`; скриншоты просмотрены. После исправления переноса длинной подписи целевой UI-сценарий дополнительно прошёл на финальной сборке (`SleepInteractiveLayoutRetry-20261110`). Работа на паре физических устройств остаётся непроверенной; в режиме «только Watch» после передачи телефон не подстрахует при сбое часов. [Инструкция](SLEEP.md).

Дневник сна и умное окно (2026-11-10) — **Implemented, Linux-tested**. Третья вкладка общего дневника читает сон HealthKit после opt-in: длительность, записанные фазы и семь ночей; пересечения и источники не удваивают сон, отсутствие данных не становится нулём. AlarmKit устанавливает обязательный фиксированный резерв до отправки настроек Watch. На Watch ближайшее окно 5–30 минут подтверждается в активном приложении и использует штатную smart-alarm runtime session с экспериментальной оценкой движения, без обещания измерять текущую фазу. Резерв отменяется только после явного «Выключить» и доставки валидного подтверждения. Linux: 287 Core tests, в том числе 8 новых, portable sleep checks и проверки ресурсов/синтаксиса/локализации/форматирования. Xcode 27.2: SDK-сборка iOS/widgets/Watch и 101 Apple unit tests прошли; целевой UI-тест вкладки и редактора прошёл, оба скриншота просмотрены. Реальная ночная работа, датчики, AlarmKit-доставка и Watch-синхронизация на физических устройствах остаются непроверенными. Нужна регенерация XcodeGen; инструкции — [SLEEP.md](SLEEP.md), оставшиеся проверки — [XCODE_VALIDATION.md](XCODE_VALIDATION.md).

Российский каталог питания с резервным поиском (2026-11-10) — **Implemented, Linux-tested**. Клиент сначала ищет в perek.us через публичный маршрут своего Backend, затем в Open Food Facts при пустой выдаче, лимите или ошибке. Отмена не создаёт резервный запрос. Ключ только на сервере, вход в аккаунт не требуется. Кеш/общий бюджет ограничивают обращения поставщику, IP-лимит защищает публичный маршрут. Полные КБЖУ проверяются без подстановки нулей; источник показан в интерфейсе и сохранённых записях. Optional barcode совместим с прежними JSON payloads и помогает повторному офлайн-поиску. Linux: полный `check-linux.sh`, 279 Core tests и переносимые HTTP/routing/persistence checks; Backend: полный прогон 188 xUnit-тестов без категории PostgreSQL, форматирование и 5 Python-проверок; финальные 9 FoodSearchTests после валидации секретного заголовка прошли. Xcode 27.2: SDK-сборка и 101 Apple unit tests успешны; UI-прогон ручного ввода не прошёл из-за keyboard focus/тайм-аута и остаётся непроверенным. Инструкция подключения — FOOD_SEARCH.md. Настоящий ключ, развёртывание и покрытие конкретных товаров требуют настройки владельцем сервера; проверка заглушками не считается проверкой покрытия базы.


Неполные карточки по штрихкоду (2026-11-10) — **Implemented, Linux-tested**. Поиск отличает отсутствующий товар (status 0), найденную карточку без пригодных названия/КБЖУ и некорректный ответ API. Для неполной карточки показана точная причина и доступен прежний ручной ввод с сохранением штрихкода; вымышленные нутриенты не подставляются. Прямой запрос OFF для 7622210769459 вернул status 1 без названия и nutriments; контрольный 3017620422003 вернул Nutella с полными значениями. Поставщик базы не менялся; расширение покрытия этим исправлением не заявляется. Полный `check-linux.sh`: 279 Core tests, HTTP fixtures, ресурсы/локализация/синтаксис/форматирование прошли. Apple SDK и физический сканер в этой правке не проверялись.

Единое редактирование выполненных подходов (2026-11-09) — **Implemented, Linux-tested**. В текущей тренировке вес и повторения записанного подхода редактируются теми же ячейками и цифровой панелью, отдельная форма коррекции удалена. Core атомарно проверяет числовые изменения, сохраняет ID, completion dates и отдых; рабочий объём пересчитывается. Незавершённый ввод хранится в сессионном кеше, корректные пары сохраняются при смене поля/закрытии. Завершённая тренировка остаётся readonly; массовое копирование вниз не меняет записанные подходы. Полный `check-linux.sh`: 279 Core tests и portable/static checks прошли; сборка с Apple SDK 27.2 выполнена. 101 Apple unit tests и два UI-сценария изменения/сохранения ввода и закрытия свайпом прошли; артефакты `InlineCompletedUnits-20261109.xcresult` и `InlineCompleted-20261109.xcresult`. Оставшиеся ручные сценарии перечислены в XCODE_VALIDATION.md.

Шторки без стрелок закрытия (2026-11-09) — **Implemented, Linux-tested**. Удалены стрелки в заголовках активной тренировки, упражнения и сохранённой тренировки, а также нижняя стрелка в readonly-упражнении. Системный drag indicator и закрытие свайпом сохранены; счётчик упражнения занимает освободившееся место, таймер остаётся по центру. UI-сценарии переведены с нажатия стрелок на drag вниз. Схема хранения и XcodeGen-конфигурация не менялись.

Предыдущие заметки к подходам (2026-11-09) — **Implemented, Linux-tested**. При создании строки упражнения заметки копируются вместе с количеством и значениями выполненных подходов из той же предыдущей сессии и показываются в существующей колонке заметок. Явная заметка текущего плана имеет приоритет; разминка и рабочие подходы сопоставляются отдельно. Последующее редактирование/удаление не восстанавливается из истории, исходная тренировка не меняется. Полный Linux-прогон: 277 Core tests и portable/resource/syntax/localization/lint checks. Xcode 27.2, iPhone 17 Simulator / iOS 27.2: 101 Apple unit tests и целевой UI-тест заметок/повторного открытия прошли. Артефакт: `PreviousSetNotes-20261109.xcresult`. Схема хранения и XcodeGen-конфигурация не менялись.

Сохранение незавершённого ввода и перенос предыдущих подходов (2026-11-08) — **Implemented, Linux-tested**. Текст полей принадлежит активной сессии и сохраняется между открытиями карточки; корректные пары веса/повторений записываются через Core/AppStore при смене поля, закрытии или уходе в фон, без выполнения подхода. Ошибка записи не уничтожает черновик. Новые пустые строки упражнений при старте/добавлении/замене получают число, индивидуальные значения и структуру выполненных подходов из одной последней подходящей сессии; повторные вхождения упражнения сопоставляются отдельно. Уже редактируемые строки и ручные удаления не восстанавливаются повторно. Шаблоны из истории сохраняют plannedSets и для обычных разных числовых целей. Области мышц вложены в блок родительской мышцы, родитель указан в раскрывающей кнопке, VoiceOver и итоговой подписи. Схема хранения и capabilities не менялись. Полный Linux-прогон: 274 Core tests, portable checks, Swift 6 strict concurrency, ресурсы/локализация/синтаксис/форматирование. Mac: Xcode 27.2 (27B52), iPhone 17 Simulator / iOS 27.2 — 101 Apple unit tests и 5 целевых UI tests прошли, скриншоты проверены; финальный каталог 1028 RU/EN ключей проверен xcstringstool. **Requires Xcode validation** для оставшихся ручных сценариев Dynamic Type, VoiceOver, EN/тёмной темы и физического устройства; перечень и артефакты — в XCODE_VALIDATION.md.

Последняя полная проверка Swift: 2026-11-09, Ubuntu 24.04 x86_64, Swift 6.2.1, Swift language mode 6, 278 Core tests и все portable checks. Apple-прогон 2026-11-08: Xcode 27.2 (27B52), iPhone 17 Simulator / iOS 27.2 — 101 Apple unit tests и 5 целевых UI tests прошли; настоящие скриншоты проверены. Проверка серверов: 2026-11-08, .NET 10 и PostgreSQL 18; 193 xUnit-теста, форматирование и пять Python-тестов скриптов прошли. Пять вариантов небезопасной конфигурации startup дополнительно прошли 20 повторных прогонов (100 проверок).

**Implemented** означает наличие реализации в исходниках. **Linux-tested** означает выполнение тестов соответствующего Core-кода либо серверных unit/HTTP/PostgreSQL-сценариев; состав проверки указан в строке модуля. Синтаксический разбор Apple-файлов и проверка ресурсов не считаются функциональным тестированием SwiftUI или Apple SDK.

## Границы текущей реализации

Watch записывает отдельный стартовый план и передаёт готовую тренировку на iPhone; live mirroring и датчики HealthKit на Watch не реализованы. На iPhone добавлен явный живой приём через HealthKit для AirPods Pro 3; проверка SDK и реального устройства ещё требуется, автоматическое восстановление системной сессии после завершения процесса не реализовано.
