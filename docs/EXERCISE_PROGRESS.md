# Графики по упражнениям

В **Результаты → Прогресс по упражнениям** выберите упражнение и период: 4, 12, 26 недель или всё время. По умолчанию открываются последние 12 недель. Выбор месяца/года в календаре относится к календарной сводке; период графиков задаётся отдельно.

Доступны пять показателей:

| График | Значение за одну завершённую тренировку |
| --- | --- |
| Максимальный рабочий вес | Наибольший дополнительный вес среди выполненных рабочих подходов |
| Рабочий объём | Сумма веса в кг × повторения по выполненным рабочим подходам |
| Расчётный 1ПМ | Наибольшая оценка Эпли среди рабочих подходов с весом на 1–12 повторений |
| Рабочие повторения | Сумма повторений в выполненных рабочих подходах |
| Рабочие подходы | Число выполненных рабочих подходов |

Нажатие или ведение пальца по графику выбирает ближайшую тренировку. Её дата и значения отображаются в карточках; выбор общий для пяти графиков. До выбора показываются показатели последней тренировки выбранного периода. Для веса, объёма и 1ПМ используются выбранные пользователем кг/фунты; повторения и подходы не преобразуются.

## Переход из тренировки

В активной тренировке и в подробностях завершённой тренировки у каждого упражнения есть ссылка **Прогресс упражнения**. Открывается история только этого exercise UUID за всё время, с теми же фильтрами и графиками. У завершённой тренировки выделяется её точка, если есть выполненные рабочие подходы. Совпадение времени двух тренировок не меняет выбранный workout UUID.

Текущая незавершённая тренировка в графики не входит. Если истории ещё нет, показано объяснение. Переход к графикам не ставит тренировку на паузу и не меняет её данные; вернуться можно обычной навигацией назад. В демо используются изолированные демонстрационные тренировки с обозначением режима.

## Правила данных

- Разминка, невыполненные подходы, отменённые/незавершённые тренировки и тренировки с будущей датой начала исключены.
- Повторяющиеся строки одного упражнения внутри сессии объединяются. Разные UUID с одинаковым названием не смешиваются; переименование с сохранением UUID сохраняет историю.
- Упражнения без дополнительного веса доступны в выборе: их повторения и подходы считаются, добавленный вес/объём равны нулю. Вес тела не подставляется.
- При отсутствии подходящих подходов 1ПМ отсутствует, а не заменяется нулём. Расчёт не является рекомендацией нагрузки.
- Один отсчёт соответствует одной тренировке, а не календарному дню. Несколько сессий за день сохраняются отдельно.
- Период отсчитывается календарными неделями от текущей даты/времени с часовым поясом пользователя, включая DST; начальная граница включена.
- Изменение, удаление и импорт истории обновляют серии. Экран из тренировки не переключается на другое упражнение при удалении его данных.
- Схема хранения, архивы и UUID не изменены. Данные не отправляются внешнему сервису.

## Статусы и проверки

- **Implemented:** Core-расчёты, presentation model, пять нативных Swift Charts, периоды, выбор точки, переходы из active/history и RU/EN.
- **Linux-tested:** семь новых Core-тестов, общий набор 99 тестов. `Tests/PortableProgressChecks/main.swift` исполняет настоящие Foundation/Observation модели: выбор, периоды, bodyweight, удаление, точный workout UUID и обновление. Проверены strict concurrency, ресурсы, локализация, синтаксис и форматирование Apple-файлов.
- **Requires Xcode validation:** SwiftUI/Charts compilation, gestures, оси, навигация, VoiceOver, RU/EN, Dynamic Type и написанные Apple unit/UI tests. На Linux это не проверялось.
- **Requires Apple Developer configuration:** новых capabilities нет; обычный signing приложения.

API сверены по официальной документации: [chartXSelection(value:)](https://developer.apple.com/documentation/swiftui/view/chartxselection(value:)), [настройка осей](https://developer.apple.com/documentation/charts/customizing-axes-in-swift-charts), [ChartContent и доступность](https://developer.apple.com/documentation/charts/chartcontent). Сценарии на Mac: [XCODE_VALIDATION.md](XCODE_VALIDATION.md).
