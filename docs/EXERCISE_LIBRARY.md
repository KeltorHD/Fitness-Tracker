# Библиотека упражнений

В приложение встроена локальная подборка **100 силовых упражнений** из free-exercise-db с **200 фотографиями**, русскими названиями, поисковыми синонимами и тремя шагами техники на каждое упражнение. Исходная база на зафиксированной ревизии содержит 876 записей; остальные записи не импортировались и не выдаются за переведённые.

## Использование в приложении

- Сегодня → Библиотека упражнений: просмотр и поиск.
- Добавить упражнение в тренировке или плане: каталог → карточка → Добавить упражнение.
- Техника выполнения в тренировке, редакторе плана и истории: та же карточка с фотографиями.
- Поиск по русскому названию, синонимам, мышцам, инвентарю и исходному английскому имени. Регистр, лишние пробелы и различие е/ё не мешают поиску.
- Фильтры по группе мышц и оборудованию.
- Карточка: две фотографии с ручным перелистыванием, мышцы, инвентарь, уровень и нумерованная техника.
- Источник и исходная лицензия доступны из каталога и настроек.

Фотографии встроены в iOS bundle и не требуют интернета, регистрации или API-ключа. Общий размер исходных JPEG — 12 878 179 байт. Они показывают отдельные положения; настоящие GIF/видео этим импортом не добавлялись. На watchOS и в widget extension попадают только небольшие текстовые данные Core, без копирования фотографий.

## Данные и совместимость

`Exercise` не изменён: существующие SwiftData/CloudKit JSON-пакеты продолжают декодироваться. `ExerciseLibraryEntry` хранит вспомогательные метаданные отдельно. Восемь старых UUID и порядок упражнений стартовых планов сохранены. Старая запись с прежним описанием получает актуальную карточку по UUID, без переписывания истории и рекордов.

SPM копирует `Sources/FitSessionCore/Resources/ExerciseLibrary.ru.json` и читает его через `Bundle.module`. Все поля, кроме исходного имени для поиска и оригинального текста лицензии, представлены пользователю на русском. Инструкции — сокращённая адаптация, а не дословный перевод. Поисковые синонимы — вспомогательные названия, не замена привязанному к записи виду упражнения.

XcodeGen включает `Resources/ExerciseMedia` как folder reference в resources только главного iOS target, сохраняя подпапки источника. ExerciseImageLoader читает файлы на отдельном actor и кэширует Data в NSCache (40 записей, cost limit 32 МБ); UIImage создаётся в presentation model на MainActor. SwiftUI .task управляет загрузкой и отменой. Если ресурс отсутствует, карточка показывает ошибку и повтор загрузки; сетевой подмены нет.

## Воспроизводимый импорт

```bash
# Обычная пересборка из уже сохранённой выборки; сеть не используется:
python3 scripts/import-exercise-library.py
python3 scripts/validate-exercise-library.py

# Явное повторное скачивание отсутствующих материалов из закреплённой ревизии:
python3 scripts/import-exercise-library.py --download-only
```

Переводы поддерживаются в `Data/ExerciseLibrary/*.tsv`; исходные записи, лицензия и hashes — в `ThirdParty/free-exercise-db`. Скрипт генерирует resource JSON и не переводит текст автоматически. При обновлении источника нужно отдельно проверить лицензию, контент, соответствие фотографий и переводы. Готовая локальная библиотека не зависит от доступности GitHub.

## Проверки и статусы

- **Implemented:** библиотека, русский текст, локальные фотографии, поиск, фильтры и SwiftUI-карточки.
- **Linux-tested:** загрузка SPM resource, сохранение ID, локализация, поиск е/ё и aliases, комбинации фильтров, ошибки импорта, совместимость старого Exercise JSON; SHA-256 всех 200 фотографий и повторяемость генерации.
- **Requires Xcode validation:** SwiftUI type checking, копирование folder resources, листание изображений, добавление в планы/тренировки, Dynamic Type, VoiceOver и первая загрузка в авиарежиме.
- **Requires Apple Developer configuration:** отдельные ресурсы разработчика не нужны; обычный signing приложения.

Новые UI-тесты не запускались на Linux. Иллюстративные макеты: [previews](previews/README.md). Полная атрибуция: [NOTICE.ru.md](../ThirdParty/free-exercise-db/NOTICE.ru.md).
