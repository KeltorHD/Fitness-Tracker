# Библиотека упражнений

В приложение встроены все **876 упражнений** зафиксированной ревизии free-exercise-db: русские названия, основные и вспомогательные мышцы, оборудование, поиск и **1746 оригинальных фотографий**. Каталог включает силовые упражнения, растяжку, плиометрику, тяжёлую атлетику и кардио. У трёх записей в источнике нет фотографий, у пяти — инструкций; интерфейс явно сообщает об отсутствии материалов.

## Использование в приложении

- Сегодня → Библиотека упражнений: просмотр и поиск.
- Добавить упражнение в тренировке или плане: каталог → карточка → Добавить упражнение.
- Техника выполнения в тренировке, редакторе плана и истории: та же карточка с фотографиями.
- Поиск по русскому названию, синонимам, мышцам, инвентарю и исходному английскому имени. Регистр, лишние пробелы и различие е/ё не мешают поиску.
- Фильтры по группе мышц и оборудованию, включая выбор группы на схеме тела.
- Карточка: исходные фотографии с ручным перелистыванием либо готовая ИИ-анимация, мышцы, инвентарь, уровень и нумерованная техника при наличии в источнике.
- Источник и исходная лицензия доступны из каталога и настроек.

Фотографии встроены в iOS bundle и не требуют интернета, регистрации или API-ключа. Общий размер исходных JPEG — 98 671 281 байт. Они показывают отдельные положения. Для 11 упражнений добавлены независимо созданные ИИ-иллюстрации: постер, восемь JPEG-кадров и GIF. SwiftUI воспроизводит кадры через TimelineView, позволяет поставить на паузу и показывает статичный кадр при Reduce Motion. Это иллюстрации движения, а не видеозапись или подтверждённая тренером техника. Новая генерация остановлена по просьбе пользователя; ещё 26 готовых наборов сохранены локально в output/exercise-generation и не включены в bundle/коммит каталога. На watchOS и в widget extension попадают только небольшие текстовые данные Core, без копирования фотографий.

## Данные и совместимость

`Exercise` не изменён: существующие SwiftData/CloudKit JSON-пакеты продолжают декодироваться. `ExerciseLibraryEntry` хранит вспомогательные метаданные отдельно. UUID и названия прежних 100 упражнений, включая восемь legacy UUID, и порядок упражнений стартовых планов сохранены; проверка зафиксирована в preserved-identities.json. Старая запись с прежним описанием получает актуальную карточку по UUID, без переписывания истории и рекордов.

SPM копирует `Sources/FitnessTrackerCore/Resources/ExerciseLibrary.ru.json` и `ExerciseLibrary.en.json` и читает их через `Bundle.module`. Прежние 100 русских адаптаций сохранены. Из 776 новых записей 774 помечены как автоматический перевод, две переведены вручную; исправлена часть спортивной терминологии в названиях. Полная ручная проверка новых переводов не выполнена. Короткие инструкции разбиты на шаги и при необходимости дополнены общими указаниями безопасности. Происхождение и hashes исходных текстов описаны в translation-provenance.json. Английские инструкции воспроизводят оригинал без пустых строк и не отмечаются как машинный перевод. Обе версии содержат одинаковые 876 UUID, source IDs и пути к фотографиям. Локализация выбирается при отображении, сохранённая история не переписывается. Поиск поддерживает оба языка и русские aliases. Оригинальный текст лицензии остаётся без перевода. Поисковые синонимы — вспомогательные названия, не замена привязанному к записи виду упражнения.

XcodeGen включает `Resources/ExerciseMedia` как folder reference в resources только главного iOS target, сохраняя подпапки источника. ExerciseImageLoader читает файлы на отдельном actor и кэширует Data в NSCache (40 записей, cost limit 32 МБ); UIImage создаётся в presentation model на MainActor. SwiftUI .task управляет загрузкой и отменой. Если ресурс отсутствует, карточка показывает ошибку и повтор загрузки; сетевой подмены нет.

## Воспроизводимый импорт

```bash
# Обычная пересборка из уже сохранённой выборки; сеть не используется:
python3 scripts/import-exercise-library.py
python3 scripts/validate-exercise-library.py

# Явное повторное скачивание отсутствующих материалов из закреплённой ревизии:
python3 scripts/import-exercise-library.py --download-only
```

Переводы поддерживаются в `Data/ExerciseLibrary/*.tsv`; исходные записи, лицензия и hashes — в `ThirdParty/free-exercise-db`. generated-media.json содержит привязку готовых ИИ-материалов, generated-media.provenance.json — запросы генерации и SHA-256 каждого файла. Материалы FitSession не извлекались. Скрипт генерирует resource JSON и не переводит текст автоматически. При обновлении источника нужно отдельно проверить лицензию, контент, соответствие фотографий и переводы. Готовая локальная библиотека не зависит от доступности GitHub.

## Проверки и статусы

- **Implemented:** библиотека RU/EN, локальные фотографии, поиск, фильтры и SwiftUI-карточки.
- **Linux-tested:** загрузка SPM resource, сохранение ID, локализация, поиск е/ё и aliases, комбинации фильтров, ошибки импорта, совместимость старого Exercise JSON; SHA-256 всех 1746 оригинальных фотографий и готовых ИИ-материалов и повторяемость генерации.
- **Requires Xcode validation:** SwiftUI type checking, копирование folder resources, листание изображений, воспроизведение/пауза/Reduce Motion и retry анимации, добавление в планы/тренировки, Dynamic Type, VoiceOver и первая загрузка в авиарежиме.
- **Requires Apple Developer configuration:** отдельные ресурсы разработчика не нужны; обычный signing приложения.

Новые UI-тесты не запускались на Linux. Иллюстративные макеты: [previews](previews/README.md). Полная атрибуция: [NOTICE.ru.md](../ThirdParty/free-exercise-db/NOTICE.ru.md).
