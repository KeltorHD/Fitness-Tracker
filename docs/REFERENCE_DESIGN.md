## Визуальная система

- Белый фон главных экранов, крупные системные заголовки, чёрный текст, оранжевый акцент `#FF4F33`.
- Светло-серые поверхности, крупные скругления, компактные серые chips вместо прежних зелёных промокарточек.
- Четыре вкладки: Дневник / Каталог / Результаты / Настройки.
- Стандартные TabView, ToolbarItemGroup и Menu получают системный Liquid Glass на iOS 26. Самостоятельной имитации стекла через blur нет.
- Сохраняются GlassEffectContainer, glassEffect, glassEffectID, matchedGeometry и glass/glassProminent для панели активной тренировки.
- Светлая, тёмная и автоматическая тема; системные цвета адаптируются к теме. Реальный контраст и размеры требуют проверки на Mac.

## Данные и поведение

В UI нет импортированных чисел со скриншотов. Дневник/календарь используют сохранённые completed workouts, локальный Calendar, интервалы реальных тренировок и реальный объём. ЛР в недельной сводке — число упражнений, где увеличился максимальный рабочий добавленный вес; первое положительное значение считается первым рекордом, разминки и собственный вес не учитываются.

Повтор создаёт новую сессию с новыми идентификаторами, сохраняя цели выполненных подходов и UUID самих упражнений. Даты выполнения, паузы и исторические заметки не копируются. Историческая тренировка не меняется. Если уже есть активная сессия, приложение открывает её.

При создании шаблона из истории число подходов сохраняется, а начальные повторения/вес берутся из первого выполненного подхода каждого упражнения: текущая модель шаблона использует одинаковую цель внутри упражнения. Перед сохранением значения доступны в редакторе.

Третья метрика карточки — выполненные подходы вместо вымышленных калорий. Функции измерения веса тела, окружностей и фотопрогресса не добавлены автоматически; пустые карточки с неработающими кнопками не показываются. Это граница реализации по сравнению со всем функционалом исходного приложения.

Отключение автоблокировки действует только при активной тренировке в foreground. Пауза, завершение и уход в фон возвращают обычное поведение iOS; этот параметр не обеспечивает бесконечное фоновое выполнение.

## Уточнение экрана результатов

Просмотрены предоставленные пользователем IMG_1609.PNG (текущий экран) и IMG_1610.PNG (образец). Файлы остаются локальными референсами, не включены в коммит или bundle. Переработаны TrainingMonthCard, поверхности/скругления разделов Results и контурные подписи системного TabView. Круг теперь задаёт размер календарной ячейки, а текст даты находится в overlay: его intrinsic size не должен сжимать сетку в мелкие клетки с многоточиями. Для accessibility sizes сводка переносится под календарь.

Переключение месяца сохранено в работающем меню «История → …». Верхние year/plus controls используют основной цвет, карточки Results — адаптивный нейтральный asset ResultsSurface. Контурные SF Symbols получают локальное значение SymbolVariants.none в labels tabs: [официальный API](https://developer.apple.com/documentation/swiftui/environmentvalues/symbolvariants).

По дополнительному требованию пользователя добавлена рабочая карточка «Весы» и значение веса тела каждой тренировки. Счётчик, тренировочные дни, вес и изменение берутся из реальных сохранённых данных. Данные 84/67 из образца не подставляются. Графики упражнений сохранены. [Поведение веса](BODY_WEIGHT.md).

На Linux проверены исходники и ресурсы. Rendering, фактическая геометрия календаря, вид иконок на выбранной вкладке и точность совпадения с образцом требуют Xcode. Эти правки не являются новыми скриншотами или доказательством визуального результата.

## Тренировка и упражнение по IMG_1612 / IMG_1613

Оба изображения просмотрены из корня; исходные PNG не менялись и не включены в bundle/коммит. Тренировка показывает дату в верхней панели, оранжевую шапку, три реальные метрики и компактный список. Нажатие строки открывает упражнение в контексте этой тренировки. Фото остаются лицензированными локальными free-exercise-db, а не иллюстрациями из референса.

Отдельная карточка использует оранжевый фон, белую адаптивную поверхность с радиусом 28, крупные поля вес × повторы, номера подходов и нативные glass/glassProminent controls. Номер выбирает незавершённый подход, ✓ сохраняет его через AppStore → WorkoutEngine, + добавляет следующий, стрелки переключают упражнения по row UUID. Ввод проверяет десятичный разделитель, диапазоны и кг/фунты; неизменённый вес сохраняет исходную точность. Пауза и история блокируют выполнение. Завершение тренировки остаётся отдельной подписанной кнопкой.

WorkoutExercisePresentation хранит выбранные exercise/set IDs и черновики полей при переключении упражнений. Ввод сохраняется в тренировку при выполнении подхода; Core по-прежнему определяет завершение, отдых и валидацию. Завершённая история не редактируется через карточку. Техника и все графики упражнения доступны через нижние кнопки; вес тела, пульс, заметки, повтор и экспорт сохранены.

Сетка/шрифты поддерживают Dynamic Type: поля перестраиваются вертикально на accessibility sizes, длинный заголовок и подходы прокручиваются, основной таймер допускает уменьшение по ширине. Иконки нижней панели имеют стабильный размер и доступные подписи. Это реализовано в исходниках; фактическая геометрия, VoiceOver, keyboard safe areas и возврат navigation bar требуют Xcode.
