# Проверки, требующие Xcode

Все пункты ниже остаются **непроверенными** до выполнения на macOS/устройстве. Отметьте устройство, ОС, Xcode version, результат и ссылку на исправление при первом прогоне.

## Дни тренировок и шаблоны «На сегодня»

- [ ] В «Параметрах выполнения» создать/изменить шаблон: выбрать несколько дней, сохранить, открыть снова; снять все дни. Отмена не сохраняет черновик. Старые шаблоны открываются без дней; экспорт/импорт сохраняет дни и остальные параметры.
- [ ] При старте совпадающие с местным днём шаблоны идут первыми в «На сегодня», остальные — в «Другие шаблоны», без дублей; внутри групп сохраняется исходный порядок. Если совпадений нет, обычный список без пустых групп; если совпадают все, нет пустой группы «Другие шаблоны». Ни один шаблон не отмечается автоматически.
- [ ] Выбрать несколько шаблонов из обеих групп, снять отметку и выбрать снова: порядок запуска следует выбору, сводка и объединение работают как прежде. Свободный старт, отмена, пустой список и удаление/изменение шаблона при reload остаются рабочими. Запуск вне назначенного дня разрешён, пропуск не переносит дни.
- [ ] Оставить выбор открытым через полночь, сменить время/часовой пояс, свернуть и вернуть приложение на следующий день: группы обновляются, выбор сохраняется по UUID. Проверить RU/EN, порядок дней с началом недели в понедельник/воскресенье, Dynamic Type, VoiceOver, обе темы и доступность длинной формы. На Linux SwiftUI/Apple SDK не проверены; Core календарные сценарии проверяются отдельно.

## Несколько типов инвентаря в каталоге

- [ ] В каталоге и выборе упражнения из шаблона/тренировки отметить «Штанга» и «Гантели»: меню отмечает оба типа, подпись перечисляет их, выдача включает любой выбранный тип. Снять одну отметку; выбрать «Весь инвентарь» — ограничения только по инвентарю снимаются, поиск и группы мышц сохраняются.
- [ ] Совместить несколько типов инвентаря с несколькими группами мышц и поиском, сменить RU/EN: выбор и состав результатов сохраняются. Пустая выдача позволяет сбросить все фильтры. Проверить VoiceOver, Dynamic Type, длинные подписи и обе темы; запустить ExerciseLibraryFilterTests. На Linux Apple UI/XCTest не выполнялись.

## Параметры выполнения шаблона

- [ ] Новый шаблон: «Параметры выполнения» свёрнуты; в основном списке упражнений остаются техника и удаление. Раскрыть блок: отдых по умолчанию «Произвольный», ниже — подходы, повторения и вес каждого упражнения. Добавление/удаление упражнения корректно обновляет оба списка.
- [ ] Настроить подходы/повторения/вес и отдых «По таймеру», свернуть блок, сохранить и открыть снова: значения сохраняются. Проверить старый шаблон с заданным отдыхом и шаблон из истории с индивидуальными plannedSets; сворачивание не меняет данные, отмена не сохраняет правки.
- [ ] Выбрать «Произвольный», сохранить: в обзоре отдых подписан «Произвольный», после выполнения подхода автоматический таймер не запускается. «По таймеру» позволяет задать секунды, и после старта отдых работает как прежде. Отдых общий для всех упражнений.
- [ ] Проверить RU/EN, Dynamic Type, VoiceOver, тёмную тему, длинные названия и десятичную клавиатуру поля веса. На Linux SwiftUI-сценарии не выполнялись.

## Группы мышц шаблона

- [ ] Создать и изменить шаблон: выбрать одну/несколько основных групп, сохранить, открыть снова; снять все отметки. Отмена не сохраняет черновик. Старые шаблоны открываются без выбранных групп, импорт/экспорт сохраняет выбор.
- [ ] Проверить подписи групп в каталоге шаблонов, обзоре и выборе перед стартом: RU/EN, Dynamic Type, VoiceOver, светлая/тёмная тема, длинный список групп.
- [ ] Из редактора добавить упражнение: фильтр сразу включает все выбранные группы (любая из них), совместим с поиском/инвентарём/сменой языка. Меню позволяет менять несколько групп и сбрасывать их; схема тела подсвечивает выбранные группы и позволяет добавлять/снимать отдельные группы. Пустая выдача позволяет сбросить фильтры. Повторное открытие выбора использует группы шаблона, временная смена фильтра не меняет шаблон. Без групп доступен весь каталог. Запустить ExerciseLibraryFilterTests; на Linux Apple-тесты не выполнялись.

## Центральная кнопка начала тренировки

- [ ] Выбор шаблонов: без выбора запуск по шаблонам отключён, свободный старт доступен; можно выбрать несколько строк, снять отметку и выбрать заново. Видны порядок выбора, счётчик и отметки, запуск выполняется отдельной кнопкой; закрытие крестиком/свайпом не сохраняет выбор и не создаёт сессию.
- [ ] Объединить два пользовательских шаблона с общими упражнениями и разными целями: один exercise UUID добавляется один раз с полными параметрами первого вхождения (включая разминку/дропсеты), разные UUID с одинаковым названием остаются. Упражнения следуют порядку выбора, отдых берётся из первого шаблона; исходные шаблоны не меняются. Длинное общее имя ограничено 80 символами.
- [ ] После выбора шаблон изменён/удалён при reload: запуск использует актуальные шаблоны, удалённый не участвует, при пустом выборе кнопка отключена. Длинные списки доступны прокруткой выше закреплённой кнопки, medium/large, RU/EN, Dynamic Type и VoiceOver с выбранным состоянием. Проверить `testCenterActionCombinesMultipleTemplatesAndAllowsDeselection`, обновлённый single-template UI test и два combined-template AppStoreTests; на Linux Apple-тесты не запускались.

- [ ] После `xcodegen generate` собрать WorkoutNavigationBar, WorkoutStartView и RootView с iOS 26 SDK. Проверить настоящие GlassEffectContainer/glassEffect и интерактивное стекло кнопки. [Apple: Liquid Glass для custom views](https://developer.apple.com/documentation/swiftui/applying-liquid-glass-to-custom-views).
- [ ] Вкладка и заголовок страницы называются «Шаблоны» (EN: Templates). Четыре вкладки сохраняют навигацию и состояние; системная панель скрыта, новая не дублируется. Между «Шаблонами» и «Результатами» кнопка выступает примерно на 12 pt, контур стекла плавно её огибает. Проверить компактный iPhone, landscape, iPad, safe areas и home indicator; длинные списки прокручиваются выше панели, клавиатура не закрывает поля.
- [ ] На каждой вкладке открыть выбор и закрыть крестиком/свайпом: сессия не создаётся. Выбрать свободный старт, затем сохранённый пользовательский шаблон; состав и параметры шаблона сохраняются. Пустой каталог показывает объяснение и оставляет свободный старт доступным; длинный список шаблонов прокручивается, sheet раскрывается до large.
- [ ] Выбор закрывается до открытия тренировки. Быстрые повторные нажатия, сворачивание/возврат, пауза, foreground reload и workout URL во время выбора не создают второй sheet или тренировку. Активная сессия открывается сразу; выбор другого шаблона не заменяет её. Ошибка записи показывает сообщение и позволяет повторить старт без фантомной сессии.
- [ ] Проверить RU/EN, светлую/тёмную темы, Increase Contrast, Reduce Transparency и Reduce Motion. VoiceOver читает названия вкладок, выбранное состояние и «Начать/Продолжить тренировку»; на AX размерах панель показывает иконки с сохранёнными accessibility labels. Проверить hit targets, порядок фокуса и длинные названия шаблонов при Dynamic Type.
- [ ] Запустить новые `testWorkoutStartCanBeCancelledFromEveryTab`, `testCenterActionStartsEmptyWorkoutAndResumesIt`, `testCenterActionStartsSavedTemplate`, два start-теста AppStoreTests и существующий UI suite с обновлёнными navigation selectors. Эти Apple-тесты на Linux не выполнялись.

## Пульс и шаги: история и foreground-обновления

- [ ] Кнопки «Прочитать показатели» и «Обновить показатели»: рядом видно загрузку и подсказку о разрешениях; кнопка на время запроса отключена. После результата видны время чтения, «показатели прочитаны» и количество данных, «новых данных нет» при повторе или «доступных данных нет» с пояснением. Ноль шагов считается полученным значением. При ошибке/отмене нет ложного подтверждения успеха; поздний ответ после смены режима не обновляет результат. Автоматический начальный event с идентичными данными не перезаписывает сообщение о первом чтении. Проверить RU/EN, VoiceOver и AX Dynamic Type; кнопка обновления графиков находится над результатами, обратная связь видна без прокрутки вниз.

- [ ] После `xcodegen generate` собрать HealthChartsView/HealthChartsViewModel и HealthMetricsReader с настоящим iOS SDK и Swift 6. Проверить statistics collection, async anchored queries, cancellation при background и смене дня; повторный foreground не создаёт параллельных подписок.
- [ ] Открытие «Результаты → Пульс и шаги» не запрашивает права. Включение переключателя запрашивает только чтение heartRate/stepCount. Отказ/частичный доступ/пустая история дают пустые состояния, а не вымышленные нули или утверждение об отказе пользователя. Ошибка показывает безопасный текст и позволяет повторить. Opt-out отменяет чтение и очищает отображаемую копию.
- [ ] Пульс за выбранный день и шаги за семь дней до него включительно: DST, локаль, timezone, границы месяцев/года, нет будущих значений. Свежий пульс всегда относится к текущему дню, даже при просмотре истории. Проверить единственную точку, большие наборы, разрывы, реальные источники и VoiceOver Chart/list.
- [ ] Apple Watch, Mi Fitness/HUAWEI Health, AirPods и другие разрешённые источники доступны через HealthKit независимо от выбранного профиля. Проверить фактические задержки синхронизации; прямой поток Apple Watch не реализован и не должен обещаться. Профиль Apple Watch не запускает BLE scan.
- [ ] Bluetooth и AirPods: текущий пульс/время/источник видны вверху обзора и в упражнении; график растёт по мере записи. При паузе/завершении не добавляются новые точки. Данные HealthKit в графике тренировки ограничены сегодняшним днём и границами сессии/пауз; выбранный исторический день не влияет на текущий график. Через 15 секунд без новых данных значение помечается как последнее. Потеря контакта/связи не выглядит как свежий пульс.
- [ ] В демо-профиле персональные показатели скрыты, запросов нет. В defaults хранится только opt-in; HealthKit-показатели не входят в SwiftData/CloudKit, archive или widget summary. Убедиться, что завершённый график локальной записи доступен после перезапуска.
- [ ] Запустить testHealthChartsAreAvailableWithoutRequestingAccessOnOpen и существующие UI tests записи подходов/числовой панели/прогресса упражнения с добавленным графиком. На Linux эти UI tests только parsed/linted; Core и переносимая модель проверены отдельно.

## Swift Testing: проверка типов в macOS toolchain

По пользовательскому логу macOS сборка Core tests останавливалась на вложенном `#require` и арифметике внутри `#expect` в ExerciseProgressTests. Выражение разделено на типизированные значения, условие и допуск сохранены; optional библиотеки также извлекается перед JSON encoding. На Linux 127 Core tests прошли после правки. Повторная проверка macOS остаётся необходимой.

- [ ] Запустить `swift test` toolchain выбранного Xcode: ExerciseProgressTests и ExerciseLibraryTests компилируются без type-check timeout, полный Core suite проходит. Записать версию Xcode/Swift и результат; не считать Linux-проверку подтверждением macOS/iOS-сборки.

Проверить длинное и переименованное название, Dynamic Type, VoiceOver (название и время читаются одним заголовком), узкий iPhone, RU/EN и доступность обеих соседних кнопок. Linux: только parser/lint и структура/локализация.

## Одна карточка пульса в активной тренировке

Requires Xcode validation. В обзоре тренировки должна быть одна верхняя карточка текущего пульса/графика; ниже упражнений WorkoutTrackerCard удалён. Верхняя карточка сохраняет ошибки записи/подключения и ссылки «Пульс и шаги» / «Трекер». Проверить прямой переход в Трекер и возврат, поиск/подключение Bluetooth, AirPods start/stop live, загрузку записи и retry без автоматического запроса permissions на открытие тренировки. Проверить отсутствие повторяющихся показаний/сообщений снизу, demo mode, VoiceOver, Dynamic Type и обе локали. Тот же общий компонент карточки используется в упражнении. Linux не проверяет навигацию SwiftUI или реальные датчики.

## Сворачивание верхней карточки пульса

Requires Xcode validation. В обзоре активной тренировки нажать стрелку вверх в карточке пульса: остаётся компактная строка «Пульс · значение · уд/мин» со стрелкой вниз; график, подробности, ошибки и ссылки внутри сворачиваются. Стрелка вниз возвращает полный вид. То же действие доступно в меню «Действия тренировки» как «Свернуть карточку пульса» / «Развернуть карточку пульса». Компактная карточка остаётся видимой. При отсутствии свежих данных показывается прочерк, VoiceOver сообщает об отсутствии свежего измерения.

Сохраняется прежний AppStorage key showWorkoutHeartRate: true означает полный вид, false (включая прежнее скрытие) — компактный вид; по умолчанию true. Проверить сохранение между открытиями окна, новыми тренировками и relaunch, прежнее false, персональный/demo mode, RU/EN, Dynamic Type и VoiceOver. Область нажатия стрелки — не менее 44 pt. Сворачивание не выключает сбор пульса, permissions, Live Activity или график в упражнении. Проверить свежесть в компактном виде и продолжение записи/обновления после раскрытия. Linux: parser/lint и структура/локализация; интерфейс и сохранение на устройстве не проверены.
