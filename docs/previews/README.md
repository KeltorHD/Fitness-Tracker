# Визуальные макеты FitSession

**Это макеты, а не настоящие скриншоты SwiftUI из Xcode.** Они показывают предполагаемую композицию текущих экранов с реальными встроенными фотографиями. Linux не рендерит Apple SwiftUI или нативный Liquid Glass; шрифты, системные панели, расположение элементов и стеклянные эффекты требуют проверки на Mac.

- [Общий вид трёх экранов](overview.png)
- [Библиотека упражнений](exercise-library.png)
- [Карточка с техникой и фотографией](exercise-detail.png)
- [Активная тренировка](active-workout.png)

Каждый макет содержит заметную подпись «МАКЕТ · НЕ СКРИНШОТ ИЗ XCODE». Контент берётся из той же русской библиотеки, фотографии — из free-exercise-db (Unlicense). Картинки не подтверждают компиляцию, корректность SwiftUI layout или работу Live Activity.

Редактируемые SVG лежат рядом с PNG. Воспроизведение на Linux с системными librsvg/cairo:

```bash
python3 scripts/render-exercise-previews.py
```

Код приложения остаётся нативным SwiftUI. SVG используются только как отдельные документы для просмотра дизайна и не входят в targets приложения.
