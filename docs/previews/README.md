# FitnessTracker: макеты по референсам пользователя

**Это иллюстративные макеты с демонстрационными данными, не скриншоты запуска SwiftUI в Xcode.** Композиция переработана по `IMG_1594.PNG`–`IMG_1604.PNG` и `IMG_1612.PNG`–`IMG_1613.PNG`: белый фон, оранжевый акцент, крупные заголовки, серые карточки и четыре вкладки. Native Liquid Glass и реальный layout проверяются на Mac.

Фотографии упражнений — исходные локальные ресурсы free-exercise-db (Unlicense). Приведённые названия и показатели иллюстрируют дизайн; они не добавляются в базу тренировок приложения. Оригинальные пользовательские скриншоты не копируются в bundle.

Редактируемые SVG лежат рядом с PNG. Перегенерация на Linux с системными librsvg/cairo:

```bash
python3 scripts/render-exercise-previews.py
```

Код приложения остаётся нативным SwiftUI. SVG — только документы для просмотра дизайна, они не входят в targets приложения. Карта переноса и функциональные отличия: [REFERENCE_DESIGN.md](../REFERENCE_DESIGN.md).

В `workout-flow` показаны история (слева), активный список (в центре) и отдельное упражнение (справа). В приложении кнопка ✓ выполняет выбранный подход, + добавляет подход, стрелки переключают упражнения, пауза управляет тренировкой. Кнопка завершения остаётся доступна. История открывает ту же карточку для чтения.

Макеты пульса показывают существующие экраны: Настройки → Трекер → AirPods Pro 3 и карточку пульса ниже упражнений в истории. Числа 128/126/156 — только демонстрационные. Разрыв линии иллюстрирует отсутствие измерений, а не нулевой пульс. Наличие макета не подтверждает приём с AirPods или работу HealthKit на устройстве. Подключение: [AIRPODS.md](../AIRPODS.md).
